# Руководство по `.bid` 

Формат **`.bid`** — это текстовые файлы, из которых Zilda собирает блоки, предметы, инструменты и еду.  
Если ты делаешь свой пак (`assets/packs/ИмяПака/`), этот гайд объясняет **что уже работает в игре** и **как добавить своё**.

---

## Что нового (кратко)

| Возможность | Где описано | Что даёт в игре |
|-------------|-------------|-----------------|
| **Предметы** (`items/*.bid`) | `[item]` | Иконки в инвентаре, хотбар, рука от первого лица |
| **Инструменты** | `[item]` + `[tool]` | Кирка, топор и т.д.: скорость копания, прочность, урон |
| **Еда** | `[item]`, `category = "food"` | ПКМ — съесть, восстановить здоровье (режим выживания) |
| **Модель в руке** | `model = "voxel"` / `"sprite"` | `voxel` — иконка из пикселей в 3D-кубики; `sprite` — плоская карточка |
| **Добыча блоков** | `[break]` у блока | Твёрдость, нужна ли кирка, минимальный tier |
| **Режим выживания** | при создании мира | Здоровье, полоска сердец, смерть, инструменты важны при копании |

Примеры из ванильного пака **ZildaPack**:

- `items/wooden_pickaxe.bid` — деревянная кирка  
- `items/bread.bid` — хлеб  
- `blocks/stone.bid` — камень с добычей киркой  

---

## Куда класть файлы

```text
assets/packs/ТвойПак/
├── blocks/          ← блоки мира (земля, камень, …)
│   └── stone.bid
├── items/           ← предметы, инструменты, еда
│   ├── wooden_pickaxe.bid
│   └── bread.bid
└── textures/        ← картинки, на которые ссылаются пути в .bid
    └── items/
        └── wooden_pickaxe.png
```

**Важно:** файл с секцией `[item]` и **без** `[props]` лучше класть в `items/`, а не в `blocks/`.

Ключ предмета или блока всегда с namespace пака, например: `"zilda:wooden_pickaxe"`.

---

## Общий синтаксис

```ini
# Комментарий — строка с #

[имя_секции]
ключ = значение
строка = "в кавычках"
число = 1
дробное = 2.5
флаг = true
```

- Поддерживается только **`version = 1`** в `[bid]`.
- Неизвестные секции и поля **игнорируются** (ошибки не будет, но и эффекта не будет).

---

## Секция `[bid]` (обязательна везде)

| Поле | Обязательно | Описание |
|------|-------------|----------|
| `version` | да | Сейчас только `1` |
| `key` | да | Уникальный id, например `"zilda:my_pickaxe"` |
| `name` | нет | Имя в игре; если нет — берётся из `key` |

---

## Предметы: секция `[item]`

Используется в файлах **`items/*.bid`**.

| Поле | Обязательно | Описание |
|------|-------------|----------|
| `texture` | да | Путь к PNG (обычно 16×16), от корня пака |
| `category` | нет | Тип предмета (см. таблицу ниже). По умолчанию `"material"` |
| `stack_size` | нет | Размер стака. Для инструментов часто `1`, для еды `64` |
| `model` | нет | Как рисовать в руке: `"voxel"` или `"sprite"` |
| `heal` | для еды | Сколько HP восстанавливает (2 HP = 1 сердце) |

### Категории (`category`)

| Значение | Назначение |
|----------|------------|
| `"tool"` | Инструмент — нужна секция `[tool]` |
| `"food"` | Еда — нужно поле `heal`, едят ПКМ в выживании |
| `"material"` | Обычный предмет (ресурс) |
| `"block"` | Предмет-блок (если используешь как drop) |

### Модель в руке (`model`)

| Значение | Вид в руке |
|----------|------------|
| `"voxel"` | Каждый непрозрачный пиксель текстуры — маленький 3D-кубик (как «объёмная» иконка) |
| `"sprite"` | Плоская карточка с текстурой |

**По умолчанию**, если `model` не указан:

- `category = "tool"` → **voxel**
- всё остальное → **sprite**

---

## Инструменты: секция `[tool]`

Только если `category = "tool"`. Без `[tool]` инструмент не получит свойства копания.

| Поле | Обязательно | По умолчанию | Описание |
|------|-------------|--------------|----------|
| `kind` | нет | `"pickaxe"` | Тип инструмента (см. ниже) |
| `tier` | нет | `"wood"` | Материал / уровень |
| `speed` | нет | `2.0` | Множитель скорости добычи (чем больше — тем быстрее) |
| `damage` | нет | `1.0` | Урон (задел на бой) |
| `durability` | нет | `59` | Прочность (сколько раз можно использовать) |

### `kind` — тип инструмента

| Значение | Для чего |
|----------|----------|
| `"pickaxe"` | Камень, руда и блоки с `preferred_tool = "pickaxe"` |
| `"axe"` | Дерево |
| `"shovel"` | Земля, песок, снег |
| `"hoe"` | Земледелие (по мере добавления механик) |
| `"sword"` | Бой (по мере добавления механик) |

### `tier` — уровень

| Значение | Примечание |
|----------|------------|
| `"wood"` или `"wooden"` | Деревянный |
| `"stone"` | Каменный |
| `"iron"` | Железный |
| `"diamond"` | Алмазный |

У блока в `[break]` можно указать `required_tier` — без инструмента **не ниже** этого уровня блок почти не ломается.

---

## Пример: деревянная кирка

Файл: `items/wooden_pickaxe.bid`

```ini
[bid]
version = 1
key = "zilda:wooden_pickaxe"
name = "Wooden Pickaxe"

[item]
texture = "textures/items/wooden_pickaxe.png"
category = "tool"
stack_size = 1
model = "voxel"

[tool]
kind = "pickaxe"
tier = "wood"
speed = 2.0
damage = 2.0
durability = 59
```

**В игре:** предмет в хотбаре, в руке — объёмная модель из пикселей; в выживании быстрее ломает камень и блоки с `preferred_tool = "pickaxe"`.

---

## Пример: хлеб (еда)

Файл: `items/bread.bid`

```ini
[bid]
version = 1
key = "zilda:bread"
name = "Bread"

[item]
texture = "textures/items/bread.png"
category = "food"
heal = 4
stack_size = 64
model = "voxel"
```

**В игре:** в режиме **Survival** зажми **ПКМ** с хлебом в руке — анимация поедания, +4 HP (2 сердца). В креативе еда не тратится на лечение так же строго, но предмет всё равно отображается.

## Добыча блоков: секция `[break]`

Пишется в **`blocks/*.bid`**, не в предметах.

| Поле | Обязательно | По умолчанию | Описание |
|------|-------------|--------------|----------|
| `hardness` | нет | `0.6` | «Твёрдость» — чем выше, тем дольше ломать |
| `preferred_tool` | нет | — | Какой `kind` из `[tool]` подходит лучше всего |
| `required_tier` | нет | — | Минимальный `tier` инструмента, иначе добыча почти не идёт |

### Пример: камень

Файл: `blocks/stone.bid`

```ini
[bid]
version = 1
key = "zilda:stone"
name = "Stone"

[props]
render = "opaque"
solid = true

[textures]
all = "textures/stone.jpeg"

[break]
hardness = 1.5
preferred_tool = "pickaxe"
required_tier = "wood"
```

**Связка с киркой:** игрок держит `zilda:wooden_pickaxe` (`kind = pickaxe`, `tier = wood`) и ломает камень — добыча идёт с бонусом скорости. Без кирки или с неподходящим инструментом — намного медленнее.

---

## Блоки: напоминание по секциям

Полный разбор текстур и цветов — в [bid_tutorial.md](bid_tutorial.md).

| Секция | Назначение |
|--------|------------|
| `[props]` | `render`, `solid`, `collision`, `interact`, `stack_size` |
| `[textures]` / `[colors]` | Внешний вид в мире |
| `[icon]` | Иконка в инвентаре (если блок кладут в слот) |
| `[drop]` | Как выглядит выброшенный предмет: `cube`, `crossed_quads`, `sprite` |
| `[craft]` | Рецепт крафта (результат = этот блок) |
| `[break]` | Добыча в выживании |

### Взаимодействие с блоком

```ini
[props]
interact = "crafting"
```

Открывает верстак (как у `crafting_table`).

## Как это связано в игре (схема)

```text
  items/wooden_pickaxe.bid          blocks/stone.bid
  ┌─────────────────────┐         ┌─────────────────────┐
  │ [item] category=tool│         │ [break]             │
  │ [tool] kind=pickaxe │         │ preferred_tool=     │
  │         tier=wood   │         │   pickaxe           │
  └──────────┬──────────┘         │ required_tier=wood  │
             │                    └──────────┬──────────┘
             │    игрок в Survival         │
             └──────────────┬──────────────┘
                            ▼
                   быстрее ломает камень
                   анимация взмаха кирки
```

```text
  items/bread.bid
  ┌─────────────────────┐
  │ category = food     │
  │ heal = 4            │
  └──────────┬──────────┘
             │  ПКМ в Survival
             ▼
        +4 HP, анимация у рта
```

## Чеклист: свой инструмент с нуля

1. Нарисуй **16×16** PNG → `textures/items/my_tool.png`
2. Создай `items/my_tool.bid` по образцу кирки
3. Укажи `category = "tool"` и секцию `[tool]`
4. Для блоков, которые должен быстро ломать инструмент, добавь в их `.bid`:

   ```ini
   [break]
   hardness = 1.0
   preferred_tool = "pickaxe"
   required_tier = "wood"
   ```

5. Запусти игру: `cargo run` — смотри консоль на ошибки парсинга
6. В **Creative** возьми предмет из инвентаря или выдай через хотбар, в **Survival** проверь копание

---

## Чеклист: своя еда

1. PNG 16×16 → `textures/items/my_food.png`
2. `items/my_food.bid` с `category = "food"` и `heal = …`
3. Создай мир в режиме **Survival**
4. Положи еду в хотбар, **ПКМ** — должно поесть и восстановить HP

---

## Частые ошибки

| Сообщение / проблема | Решение |
|----------------------|---------|
| Предмет не появляется | Проверь `key`, путь `texture`, файл в `items/` |
| Инструмент не ускоряет копание | У блока нет `[break]` или другой `preferred_tool` |
| Камень не ломается | Нужна кирка с `tier` ≥ `required_tier` блока |
| `unknown tool kind` | Опечатка в `kind` — только pickaxe, axe, shovel, hoe, sword |
| `unknown item category` | Только food, tool, material, block |
| Еда не лечит | Мир должен быть **Survival**, нужно `heal = …`, ПКМ с зажатием |

---

*Версия формата: **bid v1**. При обновлении движка список полей может расширяться — смотри примеры в `assets/packs/ZildaPack/`.*
